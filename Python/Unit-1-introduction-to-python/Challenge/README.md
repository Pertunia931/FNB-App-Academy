# Challenge: The Concert Ticket Booker

## Challenge Overview

For this challenge, I need to create a simple Python program that works like a digital concert ticket counter.

The program will ask the user for some information and then use that information to display a personalised ticket confirmation.

## Requirements

The program should:

1. Ask the user for their name.
2. Ask the user for the name of the band or artist they want to see.
3. Display a personalised confirmation message using an f-string.

The confirmation message should follow this format:

```text
Hey [Name]! Your tickets to see [Artist] are booked successfully!

Skills Practised
Using input()
Storing information in variables
Working with strings
Using f-strings
Creating personalised output
