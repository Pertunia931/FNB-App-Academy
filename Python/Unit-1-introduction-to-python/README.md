# Unit 1: Introduction to Python, Strings and Numbers

## Overview

This unit introduces the foundations of Python programming and how Python can be used to solve real-world problems.

I will learn how to set up a Python development environment, write and run basic Python programs, and understand how Python stores different types of information.

I will also learn about variables and basic data types such as strings, integers, floats, and booleans.

## Learning Objectives

By the end of this unit, I should be able to:

- Explain what Python is and identify three real-world applications of Python.
- Set up a Python development environment.
- Write and run a basic Python program using `print()` and `input()`.
- Declare variables using `str`, `int`, `float`, and `bool`.
- Use `type()` to identify the data type of a value.
