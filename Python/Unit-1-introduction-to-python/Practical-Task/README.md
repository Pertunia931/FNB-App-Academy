# Practical Task: Student Info Formatter

## Task Overview

For this practical task, I need to create a Python program called `student_info.py`.

The program will collect information from a user and display it as a formatted profile. The task will help me practise Python data types, string manipulation, arithmetic operations, functions, and f-string formatting.

## Requirements

The program should:

- Use `input()` to collect the user's first name.
- Use `input()` to collect the user's surname.
- Collect the user's age and convert it to an integer.
- Collect the user's favourite number and convert it to a float.
- Display a greeting using an f-string: `Welcome, [Full Name]!`
- Display the name in uppercase using `.upper()`.
- Display the name in title case using `.title()`.
- Calculate the user's age in months by multiplying their age by 12.
- Round the favourite number to 2 decimal places using `round()`.
- Use `type()` to display the data type of each collected value.
