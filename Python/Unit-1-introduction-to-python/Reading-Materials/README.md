## What is Python?

Python is a high-level, interpreted programming language that was first released in 1991. It is widely used in different areas of technology, including data science, web development, automation, machine learning, and mobile application development.

One of the things that makes Python suitable for beginners is its simple and readable syntax. At the same time, Python is powerful enough to be used for real-world applications.

## Development Environment

To start programming with Python, I need two main tools:

- **Python** – the programming language and interpreter that runs my code.
- **Visual Studio Code (VS Code)** – the code editor where I write and manage my Python programs.

I can also install the Microsoft Python extension in VS Code. It provides useful features such as syntax highlighting, error detection, and an easier way to run Python files.

For my FNB App Academy work, I can create a dedicated folder on my computer to keep my Python projects and exercises organised.
